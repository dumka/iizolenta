# Task 6: Перехват lenta.ru в Zen и Vivaldi (LeechBlock NG) и финальная проверка эпика

Epic: `docs/plans/epic-izolenta.md` · Статус: closed (2026-10-08) · Оценка: 2-3 часа (большая часть — ручные шаги пользователя на устройствах) · Зависит от: Task 5 (closed)

## Goal

Ввод `lenta.ru` в Zen (Windows) и в Vivaldi 8.2+ (Android) открывает `https://dumka.github.io/iizolenta/` с баннером «Сайт lenta.ru заизолирован». Список сайтов берётся из `https://dumka.github.io/iizolenta/sites.txt`; добавление строки в `site/sites.txt` начинает перехватывать новый сайт на обоих устройствах без правки настроек. Все критерии успеха эпика подтверждены, эпик закрыт после `review-implementation`.

## Context

- LeechBlock NG 1.8 (MV3), есть в AMO и Chrome Web Store. Настройки блока (метки из `options.html` 1.8):
  - «Enter the domain names of the sites to block (one item per line)» — оставить пустым, список грузится по URL;
  - «Load list of sites from URL» — `https://dumka.github.io/iizolenta/sites.txt`; перечитывается при старте браузера и при сохранении настроек;
  - «Enter the time periods within which to block these sites» — кнопка «All Day» (`0000-2400`), все дни недели отмечены;
  - «Enter the fully specified URL of the page to show instead of these blocked sites» — `https://dumka.github.io/iizolenta/#$U` (`$U` — URL заблокированной страницы, подставляется без кодирования; `parseRoute` в `site/lib.js` это учитывает).
- Vivaldi Android 8.2+: расширения ставятся из Chrome Web Store (в магазине включить «Версия для ПК»); работа LeechBlock на Android не проверялась — запасной вариант: расширение AdGuard с trusted-правилом `$urltransform` (эпик, Approach 3).
- Routine работает с 2026-10-08 12:49 UTC; критерий эпика «3 запуска по расписанию подряд» проверяется через `RemoteTrigger list_runs` и коммиты `news:` в `main`.

## Implementation

1. **Инструкция пользователю** `docs/setup-leechblock.md` (ссылка из README): пошагово для Zen и для Vivaldi Android — установка, создание блока, точные значения полей, сохранение, проверка; что делать, если не сработало; запасной вариант AdGuard для Android с готовым правилом; как добавить новый сайт (строка в `site/sites.txt` → push → перезапуск браузера или пересохранение настроек LeechBlock).
2. **Zen (делает пользователь, Claude проверяет по описанию/скриншоту):** установка из AMO, настройка, проверка `lenta.ru`, `https://lenta.ru/news/...`, `m.lenta.ru`.
3. **Vivaldi Android (делает пользователь):** то же. Если не работает — AdGuard по инструкции.
4. **Проверка расширяемости (критерий эпика):** добавить в `site/sites.txt` тестовый домен, согласованный с пользователем; push; дождаться деплоя; перезапустить браузеры; убедиться, что новый сайт перехватывается на обоих устройствах; затем оставить или убрать домен — по решению пользователя.
5. **Проверка routine (критерий эпика):** не меньше трёх запусков по расписанию подряд со статусом success и коммитами в `main` (либо пустой запуск без коммита, если новых статей не было — допустимо по `PROMPT.md`).
6. **Решения по выводам Task 5:** VentureBeat (429) — убрать из `feeds.toml` или оставить; HN в режиме Custom — оставить, убрать или перейти на Full. Предложить пользователю, применить выбор.
7. **Финал:** `xpowers:review-implementation` по всем требованиям и критериям эпика; при пробелах — новые задачи; при одобрении — эпик закрыт.

## Key Considerations (SRE review)

- **Сам дашборд не должен перехватываться.** `dumka.github.io` нет в `sites.txt`; при добавлении сайтов следить, чтобы туда не попал `github.io` (иначе бесконечный редирект).
- **Поддомены.** Нужно проверить, перехватывает ли запись `lenta.ru` поддомены (`m.lenta.ru`, `www.lenta.ru`); если нет — добавить строки в `sites.txt`.
- **Кеш `sites.txt`.** Pages отдаёт его с `max-age=600`; новый сайт начнёт перехватываться не раньше чем через 10 минут после деплоя и только после перезапуска браузера или пересохранения настроек LeechBlock.
- **Обход перехвата.** LeechBlock можно выключить в два клика — это осознанный выбор пользователя, не защита от себя; пароль на настройки (есть в LeechBlock) — по желанию пользователя, в инструкции упомянуть.
- **Android-специфика.** Расширения в Vivaldi Android поддерживаются не все API; признак неработоспособности — lenta.ru открывается как обычно после сохранения настроек и перезапуска.

## Anti-patterns (для этой задачи)

- НЕТ DNS/hosts-подмены (эпик).
- НЕТ своего расширения без выполнения условия «DO NOT REVISIT UNLESS» из эпика (LeechBlock и AdGuard оба не работают на Vivaldi Android).
- НЕТ списка сайтов внутри настроек LeechBlock на устройствах — только загрузка по URL (R2).
- НЕТ закрытия эпика без ручного подтверждения перехвата на обоих устройствах.
