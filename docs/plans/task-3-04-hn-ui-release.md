# Task 3.4: Блок «Обсуждают на HN» на сайте и выкатка эпика 3

Epic: `docs/plans/epic-3-actions-hn.md` · Статус: open (SRE review: approved) · Оценка: 3 часа · Ветка: `hn` → `main` · Зависит от: Task 3.3 (closed)

## Goal

На главной под «Пишут в X» — компактный блок «Обсуждают на HN» (4 последних обсуждения: заголовок, пересказ в 4 строки, «Обсуждение на HN →», очки и комментарии); пункт меню и страница `#/hn` со всеми обсуждениями за 3 дня. Ветка `hn` слита в `main`, сбор в Actions и routine публикуют обсуждения.

## Implementation

1. `site/lib.js`: `parseRoute("#/hn")` → `{view: "hn"}`; `pluralRu(n, ["очко", "очка", "очков"])` для «310 комментариев», «1 комментарий».
2. `site/app.js`: `data/hn.json` грузится независимо (третий `loadJson` в `Promise.allSettled`); `discussionCard(d)`: заголовок (ссылка на `hn_url`), пересказ, мета «420 очков · 310 комментариев · время», ссылки «Обсуждение на HN →» (`hn_url`) и «Статья →» (`url`, если есть); блок на главной под постами (`HOME_DISCUSSIONS_LIMIT = 4`, «Все обсуждения →»); страница `#/hn`; пустой/недоступный `hn.json` — блок скрыт, на `#/hn` — «Пока тихо» / «Лента порвалась» + «Подклеить».
3. `site/index.html`: пункт меню «Обсуждают на HN» (`#/hn`, `data-category="hn"`); `updateChrome` подсвечивает по `route.view`.
4. `site/styles.css`: карточка обсуждения в стиле блока постов; на главной пересказ обрезан до 4 строк; на 360 без горизонтального скролла.
5. `site/data/hn.json`: начальный пустой файл.
6. README: блок HN в описании.
7. Выкатка: тесты, headless-проверки → `git merge --no-ff hn` в `main` → push → ручной сбор (`gh workflow run collect.yml -R dumka/iizolenta-work`) → ручной запуск routine → `hn.json` на сайте.

## Key Considerations (SRE review)

- **Ссылки.** `hn_url` и `url` проходят `isSafeUrl`; `url` может быть `null` (Ask HN) — тогда ссылки «Статья» нет.
- **Склонения.** «1 комментарий / 2 комментария / 5 комментариев», «21 очко / 22 очка / 25 очков» — `pluralRu` с тестами на 1, 2, 5, 11, 12, 21, 111.
- **Порядок на телефоне.** «Важное» → «Пишут в X» → «Обсуждают на HN» → «Последние новости».
- **Слияние.** Ветка не меняет файлы данных (проверено в 3.3); `hn.json` новый — конфликтов с коммитами routine нет. Сбор в Actions берёт код из `main`: после слияния следующий сбор начнёт собирать обсуждения — routine к этому моменту уже должна читать новый `PROMPT.md` (он в той же ветке).

## Anti-patterns

- НЕТ `innerHTML`, встраиваемых виджетов HN, абсолютных путей.
- НЕТ изменений форматов `news.json`, `posts.json`.

## Success Criteria

- [ ] `node --test` (новые: `#/hn`, `pluralRu`) и `pytest` зелёные.
- [ ] Headless: блок на главной 1280/360 под «Пишут в X», `#/hn`, ссылки с `noopener`, `null`-статья без ссылки, 404 `hn.json` не ломает главную, scrollWidth 360, без ошибок в консоли.
- [ ] `hn` слита в `main`, CI и деплой зелёные; после ручного сбора и запуска routine на сайте есть обсуждения.
