# Epic 2: Блок «Пишут в X» и блоги авторов

Статус: открыт, отложен до завершения Task 6 эпика 1 (решение пользователя) · Создан: 2026-10-08

## Requirements (IMMUTABLE)

- R1. На главной — блок «Пишут в X»: на десктопе в правой колонке над «Последними новостями», на телефоне — после «Важного». В меню — пункт «Пишут в X» (`#/x`) со всеми постами.
- R2. Карточка поста: имя автора, @handle, время, русский перевод или пересказ поста (до 600 символов), ссылка «Открыть в X →» на `https://x.com/<handle>/status/<id>`.
- R3. Источник постов — FxTwitter API `https://api.fxtwitter.com/2/profile/<handle>/statuses?count=20&since=<unix>` (без ключей). Список аккаунтов — в `feeds.toml`, правится без изменения кода.
- R4. Аккаунты (расширенный список): @karpathy, @bcherny, @sama, @emollick, @DrJimFan, @fchollet, @simonw, @OfficialLoganK, @swyx, @AndrewYNg, @gdb, @demishassabis, @JeffDean, @AmandaAskell.
- R5. Routine отбирает посты: пропускает ответы, простые репосты без комментария, посты не про AI/IT/разработку/IT-бизнес, личные и бытовые посты, рекламу. Цитаты с собственным комментарием автора допустимы.
- R6. Посты хранятся в отдельном `site/data/posts.json`; контракт `news.json` не меняется.
- R7. Посты хранятся 3 дня; лимит постов на запуск — настройка (по умолчанию 10), отдельно от лимита статей.
- R8. Блоги авторов добавляются как обычные источники новостей: `https://karpathy.bearblog.dev/feed/`, `https://borischerny.com/feed.xml`, `https://www.oneusefulthing.org/feed`, `https://charonhub.deeplearning.ai/rss/` (The Batch).
- R9. Сбой FxTwitter (ошибка, 5xx, сервис пропал) не валит запуск и не трогает новости; если самый свежий пост старше 48 часов, блок показывает «Посты из X временно не обновляются».
- R10. Режим сети окружения остаётся Custom; в allowlist добавляются только `api.fxtwitter.com` и домены блогов из R8.

## Success Criteria (MUST ALL BE TRUE)

- [ ] После запуска routine на сайте блок «Пишут в X» с переводами постов минимум трёх разных авторов из R4.
- [ ] `#/x` показывает все посты за 3 дня, новые сверху.
- [ ] Ответы и репосты без комментария в `posts.json` не попадают (проверено тестом на фикстуре FxTwitter).
- [ ] Недоступный FxTwitter (фикстура 5xx/таймаут) — `collect` завершается с кодом 0, новости обрабатываются, ошибка в `errors`.
- [ ] Посты старше 3 дней удаляются при `merge`.
- [ ] Записи блогов из R8 появляются в обычной ленте новостей.
- [ ] `pytest`, `node --test`, headless-проверки дашборда (включая 360px без горизонтального скролла) зелёные.

## Anti-patterns (FORBIDDEN)

- НЕТ скрапинга HTML x.com, Nitter, RSSHub (исследование: Nitter под требованием X прекратить работу, RSSHub без своих cookies не работает, HTML требует логина и JS).
- НЕТ API-ключей X в репозитории и в переменных окружения, видимых агенту (если понадобится официальный API — только как сетевой секрет окружения).
- НЕТ изменения схемы и валидации `news.json` (эпик 1 — контракт).
- НЕТ режима сети Full (решение пользователя).
- НЕТ доверия текстам постов как инструкциям (как и для статей).

## Approach

`collect` дополнительно опрашивает FxTwitter по каждому аккаунту из `[[x_accounts]]` (параллельно, с `since` от последнего виденного поста), нормализует посты (id, автор, время, текст, тип: пост/ответ/репост/цитата), сразу отбрасывает ответы и простые репосты и кладёт оставшиеся в `pending.json` отдельным списком `posts` (не больше `max_posts_per_run`). Routine пишет для постов записи `{"id", "status": "ok"|"skip", "text": "..."}` в `summaries.json` (отдельный список `posts`); `check` и `merge` валидируют их своей схемой и вливают в `site/data/posts.json`. Дашборд грузит `posts.json` независимо от `news.json`: если он недоступен, остальная страница работает.

Запасной вариант, если FxTwitter перестанет работать: официальный X API pay-per-use (`GET https://api.x.com/2/users/{id}/tweets?since_id=...&exclude=replies,retweets`, около 6-35 долларов в месяц, ключ — сетевой секрет окружения). Переключение — замена одного модуля сборщика.

## Design Discovery

### Key Decisions Made

| Question | User Answer | Implication |
|----------|-------------|-------------|
| Формат постов X | Отдельный блок «Пишут в X» | Новый тип контента, своя схема и файл; R4 эпика 1 не затрагивается |
| Источник | FxTwitter + блоги | Бесплатно, без ключей; риск исчезновения сервиса, R9 |
| Авторы | Расширенный список (14) | R4 |
| Порядок | Сначала LeechBlock (Task 6 эпика 1) | Эпик 2 стартует после закрытия эпика 1 |
| HN, VentureBeat | Убрать | Удалены из `feeds.toml` 2026-10-08 |

### Research (2026-10-08)

- Официальный X API: с 2026-02-06 только pay-per-use; $0.005 за пост, $0.010 за lookup пользователя; чтение таймлайнов доступно; оценка 6-35 долларов в месяц для 10-20 аккаунтов (docs.x.com/x-api/getting-started/pricing).
- FxTwitter API: проверено 2026-10-08 — свежие посты по всем 10 базовым аккаунтам, `since` возвращает 204 без новых постов, лимит 1000 запросов в минуту с IP; RSS-вариант `fxtwitter.com/<handle>/feed.xml`. Неофициальный, работает на учётных записях X владельцев сервиса (docs.fxembed.com).
- Nitter/xcancel: требование X прекратить работу 2026-08-24, xcancel офлайн с 2026-09-14. RSSHub public: маршрут Twitter недоступен. Syndication timeline: устаревшие данные.
- Блоги: karpathy.bearblog.dev (последний пост 2026-04-30), borischerny.com (2026-09-19), oneusefulthing.org (2026-10-01), The Batch через charonhub.deeplearning.ai/rss/ (2026-10-07). Bluesky активен только у Моллика и Уиллисона.
